# ArkanoiD
Классическая аркада «Арканоид» (Brick Breaker), реализованная на C++ с использованием библиотеки SFML. Проект выполнен в рамках курсовой работы по дисциплине «Программирование на языках высокого уровня».

Особенности

Два режима игры — одиночный (5 уровней + секретный уровень) и мультиплеерный (3 уровня для двух игроков).

Система бонусов (Power-Ups) — положительные (удлинение платформы, мульти-мяч) и отрицательные (укорочение платформы, ускорение мяча, замедление платформы).\

Секретный уровень — разблокируется после прохождения 5-го уровня при выполнении условия.

Полноэкранный режим — переключение по клавише F11 с сохранением пропорций 800×600.

Физика отскока — угол отражения мяча от платформы зависит от точки попадания.

Модульная архитектура — разделение логики на классы Ball, Paddle, Block, PowerUp, Level и основной игровой цикл.

Управление

Главное меню

Стрелки ВВЕРХ/ВНИЗ — навигация по пунктам меню.

ENTER — выбор пункта (Start / Multiplayer / Exit).

Одиночный режим

A или стрелка влево — движение платформы влево.

D или стрелка вправо — движение платформы вправо.

ESC — пауза.

F11 — полноэкранный режим.

Мультиплеерный режим

Игрок 1 (левая платформа): A — влево, D — вправо.

Игрок 2 (правая платформа): ← — влево, → — вправо.

ESC — пауза.

F11 — полноэкранный режим.

Меню паузы

Стрелки ВВЕРХ/ВНИЗ — навигация.

ENTER — выбор (Resume / Restart / Exit to Menu).

Экраны GAME OVER / YOU WIN

R — перезапуск игры.

ESC — возврат в главное меню.

Игровой процесс

Одиночный режим: Игрок управляет платформой в нижней части экрана, отбивая мяч и разрушая блоки. Каждый разрушенный блок приносит 10 очков. При разрушении блока с вероятностью 70% выпадает бонус. Всего даётся 3 жизни. После прохождения 5 уровней активируется испытание на разблокировку секретного уровня.

Мультиплеерный режим: Два игрока управляют двумя платформами (левой и правой). На поле присутствуют два мяча. Каждый игрок защищает свою половину поля и собирает бонусы, которые применяются только к его платформе. Всего доступно 3 уровня.

Бонусы:

Положительные: удлинение платформы, мульти-мяч.

Отрицательные: укорочение платформы (8 сек), ускорение мяча (7 сек), замедление платформы (7 сек).

Секретный уровень: После 5 уровня за 20 секунд нужно 3 раза ударить платформой о правую стену. При успехе открывается секретный уровень с уникальной конфигурацией блоков и бонусом +500 очков.

Установка и запуск

1.	Скопируйте в одну папку:

o	Исполняемый файл Arkanoid.exe

o	Библиотеки SFML (sfml-graphics.dll, sfml-window.dll, sfml-system.dll)

o	Папку assets (содержит все текстуры, фоны и шрифты)

2.	Запустите Arkanoid.exe

Дополнительной установки программного обеспечения не требуется.
